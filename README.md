# pyCheck2 Printer

A cross-platform replacement for Yardi's `ycheck2.exe` check-printing application. Instead of running the original Windows program through Wine, pyCheck2 parses the `.ycheck2` file format directly and renders checks to any printer using Python and PySide6. Runs on macOS, Windows, and Linux.

---

## Features

- **Native printing on any platform** — no Wine, no Windows emulation. Sends check print jobs directly to any printer visible on your system.
- **Check list with selection** — loads all checks from a `.ycheck2` file and displays them in a list (Date, Check #, Payable To, Total). Check or uncheck individual checks before printing.
- **Running total** — the total dollar amount of all selected checks updates live as you check or uncheck items.
- **Custom default printer** — choose your check printer from a dropdown and save it as the default. The selection persists between sessions.
- **Print Copies Only mode** — when enabled, prints the NON-NEGOTIABLE copy version of each check. When disabled (normal mode), the NON-NEGOTIABLE stamp is suppressed so only clean originals are printed.
- **Print history** — every successful print job is appended to `~/.ycheck_print_history.csv`, recording the printed-at timestamp, check date, check number, payable to, and total.
- **Duplicate warning** — before printing, pyCheck2 checks your history and warns you if any selected check has already been printed, with the option to continue or cancel.
- **History viewer** — the History button opens a searchable dialog showing your full print history, newest first.
  - Search across any field: printed date, check date, check number, payable to, or total.
  - Autocomplete suggests values from your history as you type.
  - Results update live as you type.
  - Press **Esc** or click **Clear Search** to reset the filter.

## Requirements

- Python 3.11+
- PySide6

### Installing Python

**macOS** — Download the installer from [python.org/downloads](https://www.python.org/downloads/) and run it, or install via Homebrew:
```bash
brew install python
```

**Windows** — Download the installer from [python.org/downloads](https://www.python.org/downloads/). During installation, make sure to check **"Add Python to PATH"** before clicking Install.

**Linux** — You probably already know what to do.

### Install dependencies

```bash
python3 -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install -r requirements.txt
```

## Usage

```bash
.venv/bin/python3 ycheck_printer.py
```

1. Click **Browse** and select a `.ycheck2` file exported from Yardi.
2. The check list populates automatically. All checks are selected by default.
3. Uncheck any checks you do not want to print.
4. Select your printer from the dropdown. Click **Save as Default** to remember it.
5. Click **Print** — a standard macOS print dialog opens for final confirmation.
6. To review past print jobs, click **History**.

---

## File format

`.ycheck2` files are password-protected ZIP archives containing a CSV file of VB6 `Printer` object commands (`Print`, `Print2`, `FontName`, `FontSize`, `FontBold`, `CurrentX`, `CurrentY`, `ScaleMode`, `NonNegotiable`, `EndDoc`). pyCheck2 parses these commands and reproduces the check layout at the correct positions using QPainter, converting VB6 point and twip coordinates to device pixels at the printer's native DPI.

---

## Data files

| File | Purpose |
|------|---------|
| `~/.ycheck_print_history.csv` | Cumulative print history (appended after each job) |
| `~/.ycheck_printer_settings.json` | Saved default printer name |

## Notes

- The **AdvMICR** magnetic ink font used for MICR lines at the bottom of checks is substituted with Courier New, since AdvMICR is a specialty font unlikely to be installed on macOS. For production use with blank check stock that requires printed MICR lines, install an AdvMICR-compatible font and update the font substitution in `render_pages()`.
- pyCheck2 is platform independent and runs on macOS, Windows, and Linux.
- pyCheck2 is designed to work with `.ycheck2` files generated by Yardi Voyager. It is not affiliated with or endorsed by Yardi Systems.
